# Definition of done

- [ ] Acceptance criteria are met.
- [ ] Implementation is focused and follows project conventions.
- [ ] Tests cover normal, edge and relevant failure paths.
- [ ] Relevant tests, formatter, linter and static analysis were run.
- [ ] Security, privacy, dependency and compatibility impacts were reviewed.
- [ ] Logs, metrics and operational behavior are appropriate.
- [ ] Documentation, configuration examples and ADRs are updated where needed.
- [ ] Final diff contains no secrets, generated noise or unrelated edits.
- [ ] Independent review and required human approvals are complete.
- [ ] Remaining limitations and follow-up work are disclosed.
