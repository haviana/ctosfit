# Definition of Done

- Acceptance criteria satisfied and non-goals respected.
- Code follows module ownership and hexagonal boundaries.
- Server-side authorization and tenant isolation are tested.
- Domain invariants and failure paths are covered.
- Database/API compatibility and migration safety are reviewed.
- Relevant automated checks pass, or exceptions are explicitly documented.
- Documentation and operational guidance are current.
- Independent review completed; required human approval obtained.
- PR is merged only by an authorized human after required checks.
