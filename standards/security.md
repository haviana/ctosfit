# Security Standard

- Enforce server-side authentication, role authorization and object-level authorization.
- Tenant scope comes from authenticated membership, never an untrusted request field alone.
- Apply least privilege to application and CI identities.
- Validate input, protect secrets, minimize personal data and redact sensitive logs.
- Use secure defaults for CORS, CSRF, cookies/tokens, headers and error responses as applicable.
- Review dependencies and migrations for security impact.
- AI-generated workout content requires coach approval before publication.
- Security-sensitive changes require independent review.
