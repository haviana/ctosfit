# Testing

Translate acceptance criteria into observable behavior. Identify unit, integration, contract and end-to-end coverage. Include boundaries, invalid input, failure paths and regressions. Use isolated deterministic fixtures; run focused tests before broader suites. Report exact commands, observed results and untested risks.

Never delete or weaken tests merely to pass CI. Do not use production personal data.
