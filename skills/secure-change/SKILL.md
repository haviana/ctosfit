# Secure change

Identify assets, trust boundaries and untrusted inputs. Check authentication, authorization and least privilege. Validate input and encode output; assess injection and resource exhaustion. Review secrets, logs, personal data, cryptography, dependencies and CI permissions. Add security regression tests and document residual risk.

Only test authorized targets. Never include secret values in output or perform production changes without approval.
